Manage repos

Paste one or more AltStore-format source URLs (the same JSON links you'd add inside AltStore, SideStore, Feather, or eSign). Everything is fetched directly by your browser and kept only on this device.

Import / export repo list

Paste one URL per line to import several at once, or copy your current list out as plain text to back up or share.

Recommended sources

A curated set of official/community sources, based on the awesome-altstore list. Tap Add to load one straight in.

Advanced: CORS proxy (optional)

Some repos don't send the headers browsers require for cross-site JSON fetches, so loading them here may fail even though the URL is correct. If that happens, you can route metadata fetches only through a CORS proxy you trust. Download links and install buttons always point straight at the original file — the proxy is never used for the IPA itself.
